# personal-management-assistant
Full-stack personal management assistant using Angular (TS), Spring Boot (Java), Python (FastAPI) for AI, and PostgreSQL. Containerized with Docker, orchestrated via Kubernetes (Rancher Desktop), and built with CI/CD pipelines on GitHub Actions.

This project is built as a **polyglot microservice system** in a **single monorepo**. Each service is implemented in the language/framework best suited for its role, and all services are containerized to ensure portability and consistency.
